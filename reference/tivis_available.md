# Is the TIVITA Reader Available?

Present for symmetry with `cuvis.r::cuvis_available()`. TIVITA support
is pure R with no vendor SDK, so this is always `TRUE`.

## Usage

``` r
tivis_available()
```

## Value

`TRUE`, invisibly usable in conditionals.

## Examples

``` r
tivis_available()
#> [1] TRUE
```
